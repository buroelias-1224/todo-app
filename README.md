 Visit Tracker App

A simple web app that tracks user visits, displays dynamic greetings, and provides insightful visit statistics.

Features

1. Visit Time Tracking
   - Shows how long ago the user last visited the site.
   - Formats the timestamp as: `Last visited: X minutes/hours ago`.

2. Visit Counter by Page
   - Tracks and displays both the total number of visits and visits per specific page.
   - Visit stats are shown in the header.

3. Time-based Greeting
   - Displays a dynamic greeting in the header based on the current time:
     - Morning (5 AM - 11:59 AM): "Good morning!"
     - Afternoon (12 PM - 4:59 PM): "Good afternoon!"
     - Evening (5 PM - 8:59 PM): "Good evening!"
     - Night (9 PM - 4:59 AM): "Good night!"
